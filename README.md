# Task 6 - K-Nearest Neighbors (KNN) Classification

## Objective
Implement KNN Classification using a Heart Disease Dataset to predict whether a patient has heart disease.

## Tools Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

## Steps Performed
1. Loaded Heart Disease dataset
2. Explored dataset structure
3. Selected features and target variable
4. Normalized data using StandardScaler
5. Split data into training and testing sets
6. Trained KNN classifier
7. Evaluated using Accuracy Score
8. Generated Confusion Matrix
9. Generated Classification Report
10. Tested multiple K values
11. Selected the best K value

## Outcome
Successfully implemented KNN Classification and evaluated its performance in predicting heart disease.
